# 参考图背景归一 —— 虚影的真正来源

> 这份文档只讲一件事：**参考图的背景色会直接变成生成图里的"雾"**。
> 如果画面上出现一块去色的、半透明的、位置对得上参考图某处的痕迹，
> 先查参考图的背景，不要先动 `ALIGN` / `POOL` / 分辨率。

## 1. 症状

- 生成图的某个区域出现**去色的半透明雾/影子**，边界往往是一条直线或一个梯形；
- 位置大致对应参考图里某块低对比区域（薄纱、披帛、背景）；
- 提示词里已经写满该区域时**几乎不出现**；提示词写得越少，雾越重。

## 2. 根因

MOSS-Image-Edit 把参考图编码成 **VAE latent KV**。参考图里占 40%–60% 的纯黑背景
不会"被忽略"，它会成为一大批低对比 token，池化后只剩均值 —— 一片中性灰。
这些 token 参与注意力，query 被拉向它们，就在画布上铺出灰雾。

**实测（1024×1808，其余参数完全一致）**：

| 参考背景 | 右腰亮度 | 暗部占比 |
|---|---|---|
| 黑底（59.2% 纯黑） | 114.5 | 20.2% |
| 白底 | 225.3 | 7.0% |

## 3. 修法（`moss_run.py` 的 `white_bg()`，两道）

```python
# ① 有 alpha：合成到白底
# ② 无 alpha：全局刷纯黑（max(RGB) < 16），占比 > 2% 时生效
```

**为什么"从四边 floodFill"不够**：如果参考图的黑底已经被人放进一张**白画布**
（`prep_canvas` 就会这么做：人物黑底 → 缩放 → 居中放到白画布），
那么四角是白的、黑底在人物周围且**与画布边缘不连通** ——
floodFill 连起点都找不到，一个像素都刷不到，函数会把原图原样返回。

`v2sop_ref.png` 就是这种：四角 `[255,255,255]`，内部 **44.9% 纯黑**。

所以第 ② 道必须是**全局**判定，不能依赖连通性。

## 4. 判定命令

```powershell
python -c "import numpy as np; from PIL import Image; a=np.asarray(Image.open(R'<ref.png>').convert('RGB')); print('black%% = %.1f' % (100.0*(a.max(axis=2)<16).mean()))"
```

正常应为 `0.0`。非 0 就是它。

运行时也会打印一行：

```
[moss] ref-bg 44.9% black -> white
```

## 5. 三次静默失败的教训

修这个 bug 时补丁连续失效三次，而且**日志一片安静**，原因全部是
`except Exception: pass`：

| 次数 | 症状 | 真因 |
|---|---|---|
| 1 | 补丁没插进去 | 锚点写成 `def white_bg(im: Image.Image)`，实际签名是 `def white_bg(im)` |
| 2 | 插入了但无效 | PowerShell here-string 吃掉引号 → `im.convert(RGB)` |
| 3 | 仍无效 | 函数内没导入 `Image`（只有后面的 `_I`）→ `NameError` |

现已改成显式告警：

```python
except Exception as _e:
    print(f"[moss] WARN ref global-black whiten skipped: {type(_e).__name__}: {_e}")
```

**规则：这类"兜底不该静默"。** 一个被吞掉的异常会让整条链路看起来"跑通了但没效果"，
比直接报错更难查。

## 6. 残余现象（不是 bug）

删掉颜色键的那一臂（提示词只有一句基础描述）仍会在右腰留**一小片淡雾**。
这不是背景问题，而是注意力预算问题：

> **参考的价值 = 提示词的信息缺口。**
> 五个区都写满时，参考没有空隙可插；只写一句时，参考会替模型"补"它看到的低频均值。

所以正确做法是**把该区写全**（`ref_tag` 给外观、颜色键给落点），而不是去关掉参考。
