# Contributing

Small, single-purpose changes please — the tools are intentionally boring Python.

## Local checks (same as CI)

```bash
pip install -e ".[mask]"
mkdir -p build
python examples/make_demo.py build/demo.png
grabtag plan  --ref build/demo.png --spec examples/demo_spec.json --out build/reg
grabtag build --dir build/reg
grabtag colormap --depth build/demo.png --bands 3 --out build/band.png
grabtag chroma   build/demo.png --out build/keyed.png --preview build/keyed_p.png
```

## Ground rules

1. **No new hard-coded paths.** Anything machine-specific goes through an
   environment variable or a flag (`GRABTAG_SAM_CKPT`, `GRABTAG_INPUT_DIR`,
   `--out`, `--cm-dir`).
2. **No model weights, no third-party artwork** in the repository. The demo image
   must stay generated by `examples/make_demo.py`.
3. **Keep `layout.json` minimal**: `label` / `caption` / `bbox` only. Anything for
   humans goes to `layout.audit.json`.
4. **Captions describe appearance and landmark**, never identity, pose or camera.
5. If you change behaviour that the docs promise, update `README.md`,
   `README.zh.md` and `CHANGELOG.md` in the same PR.
6. **Say which channel your change touches.** Every new document (and every doc you
   rewrite) must start with one line: `> **Channel**: text only / pixels only / both`.
   If a change moves work from one channel to the other, call that out in the PR.
